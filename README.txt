KARTU QR - TEMPLATE PROFIL DIGITAL

ISI FOLDER
- template.html : file kosong, salin untuk tiap pembeli
- budi.html     : contoh yang sudah terisi
- style.css     : tampilan (dipakai semua halaman)
- script.js     : logika menampilkan data (dipakai semua halaman)
- foto/         : simpan foto pembeli di sini (budi.jpg, sinta.jpg, dst)

CARA PAKAI
1. Salin template.html, ganti namanya (mis. sinta.html).
2. Buka di VS Code, edit isi blok "const P" saja.
3. Taruh foto di folder foto/, lalu isi field foto: "sinta.jpg".
4. Lihat hasilnya: klik kanan file > Open with Live Server.

UPLOAD KE GITHUB PAGES
1. Buat repository baru (mis. kartu), upload semua isi folder ini.
2. Settings > Pages > Source: branch main > Save.
3. Link hasilnya: https://USERNAME.github.io/kartu/sinta.html
4. Jadikan link itu QR (qr-code-generator.com atau sejenisnya),
   tes scan dari HP sebelum dicetak.
